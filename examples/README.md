## Quick Start

### Basic Database Analysis
```bash
# Set your database URL
export DATABASE_URL="postgresql://user:password@localhost:5432/mydb"

# Run basic analysis
db-optimizer analyze -d $DATABASE_URL

# Get JSON output
db-optimizer analyze -d $DATABASE_URL -f json -o report.json

# Filter high severity issues only
db-optimizer analyze -d $DATABASE_URL -s high
```

## Query Rewriting

### Example 7: Rewrite Single Query
```bash
# From stdin
echo "SELECT * FROM users WHERE active = true" | db-optimizer rewrite-sql

# Output:
# Original Query:
# SELECT * FROM users WHERE active = true
#
# Optimized Query:
# SELECT id, email, name, created_at FROM users WHERE active = true LIMIT 1000
#
# Rules Applied:
# - select_star_removal (removed *)
# - limit_adder (added LIMIT for safety)
#
# Estimated Improvement: 30%
```

### Example 8: Batch Query Rewriting
```bash
# Rewrite all queries in a file
db-optimizer rewrite-sql -i queries.sql -o optimized.sql

# JSON output for programmatic use
db-optimizer rewrite-sql -i query.sql -f json
```

```bash

  -H "Content-Type: application/json" \
  -d '{
    "query": "SELECT * FROM users WHERE email = '\''user@example.com'\''",
    "explain": true
  }'

# Response includes:
# - Execution plan
# - Index recommendations
# - Cost analysis
# - Optimization suggestions
```

### Example 15: Generate Config via API
```bash
# Auto-tune configuration
curl -X POST http://localhost:8080/api/v1/config/tune \
  -H "Content-Type: application/json" \
  -d '{
    "workload": "web",
    "ram_gb": 64,
    "cpu_count": 16,
    "disk_type": "ssd"
  }' | jq .

# Get just the postgresql.conf format
curl -X POST http://localhost:8080/api/v1/config/tune \
  -H "Content-Type: application/json" \
  -d '{}' | jq -r '.data.postgresql_conf' > postgresql.conf
```

## CI/CD Integration

### Example 18: GitHub Actions
```yaml
# .github/workflows/db-health.yml
name: Database Health Check

on:
  schedule:
    - cron: '0 0 * * *'  # Daily
  push:
    branches: [main]

jobs:
  analyze:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Install db-optimizer
        run: |
          curl -L https://github.com/user/db-optimizer/releases/download/v0.1.0/db-optimizer-linux-x86_64.tar.gz | tar xz
          chmod +x db-optimizer
      
      - name: Analyze Database
        env:
          DATABASE_URL: ${{ secrets.DATABASE_URL }}
        run: |
          ./db-optimizer analyze -d $DATABASE_URL -f json -o report.json
      
      - name: Upload Report
        uses: actions/upload-artifact@v2
        with:
          name: db-health-report
          path: report.json
      
      - name: Check for Critical Issues
        run: |
          CRITICAL=$(jq '.summary.critical_issues' report.json)
          if [ "$CRITICAL" -gt 0 ]; then
            echo "Found $CRITICAL critical issues!"
            exit 1
          fi
```

## Tips & Best Practices

1. **Start with Dry-Run**
   ```bash
   # Always test first
   db-optimizer analyze -d $DATABASE_URL --auto-apply --dry-run true
   ```

2. **Use Low Risk in Production**
   ```bash
   # Conservative approach
   db-optimizer analyze -d $DATABASE_URL --auto-apply --max-risk low
   ```

3. **Monitor After Changes**
   ```bash
   # Use verification
   --verification-duration 600  # Monitor for 10 minutes
   --min-improvement 15         # Require 15% improvement
   --auto-rollback true        # Auto rollback if not met
   ```

4. **Save Reports**
   ```bash
   # Keep history
   db-optimizer analyze -d $DATABASE_URL -f json -o "report-$(date +%Y%m%d).json"
   ```

5. **Use Config Validation Regularly**
   ```bash
   # Daily config health check
   db-optimizer config-validate -d $DATABASE_URL || alert-ops-team
   ```

## Troubleshooting

### Issue: eBPF not working
```bash
# Check eBPF support
uname -r  # Should be 4.18+
cat /sys/kernel/btf/vmlinux | head -1  # Should show BTF data

# Run with CAP_BPF
sudo setcap cap_bpf+ep $(which db-optimizer)
```

### Issue: Config validation fails
```bash
# Get detailed errors
db-optimizer config-validate -d $DATABASE_URL -v

# Check PostgreSQL version compatibility
psql -d $DATABASE_URL -c "SELECT version();"
```
