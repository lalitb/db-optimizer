## Phase 1: Make It Work (Week 1-2)

### Step 1: Fix Compilation
The plugin code is written but won't compile yet because we need:

```toml
# Add to Cargo.toml
[dependencies]
tonic = "0.10"
prost = "0.12"
tokio-stream = "0.1"

[build-dependencies]
tonic-build = "0.10"
```

### Step 2: Get CNPG-I Protocol Definition
```bash
# Clone the CNPG-I repository
git clone https://github.com/cloudnative-pg/cnpg-i.git
cp cnpg-i/proto/cnpg-i.proto src/cnpg_plugin/proto/
```

### Step 3: Generate gRPC Code
Create `build.rs` in project root:
```rust
fn main() {
    tonic_build::configure()
        .build_server(true)
        .compile(
            &["src/cnpg_plugin/proto/cnpg-i.proto"],
            &["src/cnpg_plugin/proto"],
        )
        .unwrap();
}
```

### Step 4: Update proto.rs
Replace placeholder code with:
```rust
pub mod cnpg_i {
    tonic::include_proto!("cnpg_i");
}
```

## Phase 2: Build Docker Image (Week 3)

### Dockerfile
```dockerfile
FROM rust:1.75 as builder
WORKDIR /app
COPY . .
RUN cargo build --release --bin vaanyze-cnpg-plugin

FROM debian:bookworm-slim
RUN apt-get update && apt-get install -y ca-certificates && rm -rf /var/lib/apt/lists/*
COPY --from=builder /app/target/release/vaanyze-cnpg-plugin /usr/local/bin/
ENTRYPOINT ["vaanyze-cnpg-plugin"]
```

### Build Commands
```bash
docker build -t vaanyze/cnpg-plugin:v0.1.0 .
docker push vaanyze/cnpg-plugin:v0.1.0
```

## Phase 3: Kubernetes Deployment (Week 4)

### manifests/namespace.yaml
```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: vaanyze-system
```

### manifests/secret.yaml
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: vaanyze-credentials
  namespace: vaanyze-system
type: Opaque
stringData:
  api-key: "YOUR_API_KEY_HERE"
```

### manifests/daemonset.yaml
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: vaanyze-plugin
  namespace: vaanyze-system
spec:
  selector:
    matchLabels:
      app: vaanyze-plugin
  template:
    metadata:
      labels:
        app: vaanyze-plugin
    spec:
      serviceAccountName: vaanyze-plugin
      containers:
      - name: plugin
        image: vaanyze/cnpg-plugin:v0.1.0
        ports:
        - containerPort: 50051
          name: grpc
        env:
        - name: VAANYZE_API_KEY
          valueFrom:
            secretKeyRef:
              name: vaanyze-credentials
              key: api-key
        - name: RUST_LOG
          value: "info"
        resources:
          requests:
            memory: "128Mi"
            cpu: "100m"
          limits:
            memory: "512Mi"
            cpu: "500m"
```

### manifests/rbac.yaml
```yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: vaanyze-plugin
  namespace: vaanyze-system
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: vaanyze-plugin
rules:
- apiGroups: ["postgresql.cnpg.io"]
  resources: ["clusters"]
  verbs: ["get", "list", "watch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: vaanyze-plugin
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: vaanyze-plugin
subjects:
- kind: ServiceAccount
  name: vaanyze-plugin
  namespace: vaanyze-system
```

### manifests/service.yaml
```yaml
apiVersion: v1
kind: Service
metadata:
  name: vaanyze-plugin
  namespace: vaanyze-system
spec:
  selector:
    app: vaanyze-plugin
  ports:
  - port: 50051
    targetPort: 50051
    name: grpc
  type: ClusterIP
```
