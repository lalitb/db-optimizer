## 🚀 Setup Instructions (10 minutes)

### Step 1: Create Supabase Account

1. Go to https://supabase.com
2. Click "Start your project"
3. Sign up with **any email** (even a throwaway like temp-mail.org)
4. Verify your email

### Step 2: Create a New Project

1. Click "New Project"
2. Fill in:
   - **Name**: `vaanyze-contacts` (or anything)
   - **Database Password**: Generate a strong password (save it!)
   - **Region**: Choose closest to you
3. Click "Create new project"
4. Wait 2-3 minutes for setup

### Step 3: Create the Database Table

1. In your Supabase dashboard, click **"SQL Editor"** (left sidebar)
2. Click **"New query"**
3. Paste this SQL:

```sql
-- Create contact submissions table
CREATE TABLE contact_submissions (
  id BIGSERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  company TEXT NOT NULL,
  message TEXT NOT NULL,
  newsletter BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable Row Level Security (RLS)
ALTER TABLE contact_submissions ENABLE ROW LEVEL SECURITY;

-- Create policy to allow anyone to INSERT (submit forms)
CREATE POLICY "Anyone can submit" 
ON contact_submissions 
FOR INSERT 
TO anon 
WITH CHECK (true);

-- Create policy to allow authenticated users to SELECT (view in dashboard)
CREATE POLICY "Authenticated users can view" 
ON contact_submissions 
FOR SELECT 
TO authenticated 
USING (true);
```

4. Click **"Run"** (or press Ctrl+Enter)
5. You should see: "Success. No rows returned"

## 📊 Viewing Your Submissions

### Option 1: Table Editor (Easy)
1. Go to Supabase dashboard
2. Click "Table Editor"
3. Click "contact_submissions"
4. See all submissions in a nice table
5. Click any row to see full details

### Option 2: SQL Editor (Advanced)
Run queries like:

```sql
-- Get all submissions
SELECT * FROM contact_submissions 
ORDER BY created_at DESC;

-- Get only newsletter subscribers
SELECT * FROM contact_submissions 
WHERE newsletter = true;

-- Count submissions by company
SELECT company, COUNT(*) 
FROM contact_submissions 
GROUP BY company;

-- Get submissions from last 7 days
SELECT * FROM contact_submissions 
WHERE created_at > NOW() - INTERVAL '7 days';
```

### Option 3: Export to CSV
1. In Table Editor, click the "..." menu
2. Click "Download as CSV"
3. Open in Excel/Google Sheets

## 🔒 Security Features

### What's Protected:
✅ **Anon key is safe to expose** - It's designed to be public
✅ **Can only INSERT** - Users can't read others' submissions
✅ **Can't delete** - Users can't remove data
✅ **Rate limited** - Supabase prevents spam
✅ **Row Level Security** - Database-level protection

### What You Can Do (as admin):
✅ View all submissions in dashboard
✅ Export data
✅ Run SQL queries
✅ Delete spam entries

### What Visitors CANNOT Do:
❌ View other submissions
❌ Delete data
❌ Modify existing entries
❌ Access your account

## 📧 Optional: Email Notifications

Want to get emailed when someone submits? Add a Database Webhook:

1. In Supabase, go to **"Database" → "Webhooks"**
2. Click **"Create a new hook"**
3. Choose **"contact_submissions"** table
4. Choose **"Insert"** event
5. Use a service like:
   - **Zapier** (free tier: 100 tasks/month)
   - **Make.com** (free tier: 1,000 operations/month)
   - **n8n** (self-hosted, free)

## 💡 Pro Tips

Just run SQL to add columns:
```sql

```

### 2. Create Views for Common Queries
```sql
CREATE VIEW high_priority_leads AS
SELECT * FROM contact_submissions
WHERE message ILIKE '%cloudnativepg%' 
   OR message ILIKE '%kubernetes%'
   OR message ILIKE '%50%database%';
```

Use Supabase Edge Functions to send auto-reply emails

### 4. Track Conversion
Add a `status` column:
```sql
ALTER TABLE contact_submissions 
ADD COLUMN status TEXT DEFAULT 'new';

-- Update status as you process leads
UPDATE contact_submissions 
SET status = 'contacted' 
WHERE id = 123;
```

## 🐛 Troubleshooting

### Form doesn't submit:
- Check browser console (F12) for errors
- Verify SUPABASE_URL and SUPABASE_ANON_KEY are correct
- Make sure you ran the SQL to create the table

### "relation does not exist" error:
- You didn't create the table yet
- Go back to Step 3 and run the SQL

### Can't see submissions:
- Make sure you're logged into Supabase
- Check "Table Editor" → "contact_submissions"
- Try refreshing the page

### "row-level security policy" error:
- You didn't run the RLS policies
- Go back to Step 3 and run the full SQL (including policies)
